# Юзер бота @miniviperr_bot

## Mini Viperr
Данный бот был сделан по приколу, но сейчас мы пытаемся сделать из него хорошего бота.
Для того чтобы поддержать бота и развязать нам руки т.к нормальные хостинги стоять много
можете поддержать в **личку тг** - @miniviperr и **попросив реквизиты**
## Что мы планируем сделать
Мы в будущем планируем сделать бота который сможет давать музыку по запросу, развлекать, присылать новости об обновлениях по выбору игр.
Попробуем сделать какой-нибудь маркетплейс с игровыми товарми
Сделаем нормальный секретарь мод и куча много, но на данный момент у нас не позволяет хостинг делать столько.
